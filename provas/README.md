# Pasta de Provas FGV (`provas/`)

> [!IMPORTANT]
> **Por que os PDFs não foram baixados automaticamente?**
> As páginas de download do PCI Concursos listadas em [`estudo/provas.js`](../estudo/provas.js) são protegidas por **Cloudflare Turnstile (CAPTCHA)** (`#captcha-provas`). As URLs reais dos arquivos `.pdf` só são geradas após a validação humana no navegador.
>
> **Como usar esta pasta:**
> Clique nos links abaixo para abrir no seu navegador, resolva o Turnstile do PCI Concursos e salve os arquivos `.pdf` (prova + gabarito) diretamente nesta pasta (`c:\Users\coliveirar\Desktop\A\provas\`).
